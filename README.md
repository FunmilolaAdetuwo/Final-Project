# Project Title: Advanced AI Techniques for Predicting Currency Exchange Rates: A deep learning Approach
## Overview
This repository has all the code and information needed for my research project, which uses advanced AI techniques to forecast GBP/USD exchange rates. This study aims to investigate how several machine learning models, including ARIMA, LSTM, and GRU, may be applied to precisely predict future currency fluctuations.
## Research Questions and Objectives
**Research Questions:** With an emphasis on the GBP/USD pair, how can machine learning models accurately forecast future changes in currency exchange rates? 
**Objectives:** Analyse and contrast the GRU, LSTM, and ARIMA models' performances.
Create a forecast model for the GBP/USD exchange rate that is optimised.
Provide an easy-to-use tool so that stakeholders may make wise financial choices.
## Methodology
The research trains and tests the models' forecasting skills using historical price data from yahoo Finance and macroeconomic factors from World bank data from 2004 to 2023. Extensive hyperparameter adjustment was used to improve the models' accuracy and dependability.
## Results and Analysis
According to the analysis, all models produced reliable predictions, although the LSTM model outperformed the others in terms of accuracy and dependability by a little margin. Each model's performance indicators and detailed outcomes are recorded to help with comprehension of how effective they are in practical settings.
## Conclusion
The results highlight how incorporating advanced machine learning methods into financial forecasting can be beneficial. This work offers investors and financial analysts useful tools in addition to advancing the academic field of economic forecasting.
## Usage
The repository includes instructions on how to run the predictive models and reproduce the results. To improve financial forecasts, users are urged to experiment with the models and modify them to suit their unique requirements.
